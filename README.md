RWBSGGM

R implementation of the RWBS procedure for multiple change-point
detection, refinement, and confidence interval construction in
high-dimensional Gaussian graphical models.

Installation

install.packages("remotes")
remotes::install_github("wangxianru94-rgb/RWBSGGM")

Usage

library(RWBSGGM)

See inst/examples/example_basic.R for a basic example.
